# Canada Home Improvement

Modern responsive website for Canada Home Improvement.

## Local development
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Contact form
The form is configured to submit quote requests to **farshid@canadahomeimprovement.ca** through FormSubmit. The first submission may require email verification from FormSubmit.

Before launch, replace the temporary project/gallery photos with the company's own project photos and confirm the preferred business phone number and service area.

## Deployment
This Vite site can be deployed to GitHub Pages, Netlify, Vercel, or another static host. The custom domain `canadahomeimprovement.ca` can then be pointed to the selected host.
